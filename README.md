# Ежедневник

Десктопное приложение для ведения задач на Python + Flet.

## Возможности

- Вход по логину при запуске (логин используется в отчётах).
- Задачи трёх типов: **рабочая**, **учебная**, **обычная**. У каждой задачи есть название, описание, проект и приоритет (1 — высокий, 2 — средний, 3 — низкий).
- Поиск по названию.
- Фильтрация задач: все задачи / выполненные / оставшиеся.
- Сортировка: сначала высокий приоритет / сначала низкий приоритет.
- Счётчик количества задач: сколько всего задач, сколько выполнено и сколько осталось.
- Отметка задачи выполненной одним кликом.
- Сохранение последнего вошедшего: логина, времени захода и времени выхода
- Сохранение всех заходов: логина, времени захода и времени выхода
